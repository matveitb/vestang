# vestang

Реверс прошивок Vestang.

## Структура

| Путь                 | Что там                                              |
|----------------------|------------------------------------------------------|
| `firmware/original/` | сырые дампы прошивок, как получены                   |
| `firmware/extracted/`| распаковка (не в git, воспроизводится из оригиналов)  |
| `notes/`             | заметки по каждому дампу и по железу                  |
| `tools/`             | скрипты для разбора форматов, парсеры, лоадеры        |

Подробности по прошивкам — в [`firmware/README.md`](firmware/README.md).

## Заливка прошивок

Кидай файлы в `firmware/original/`. Крупные бинари (> ~50 МБ) лучше не
коммитить напрямую — скажи, подключу git-lfs.
