# A2L из таблицы дескрипторов

`tools/mka2l.py <bin> <a2l>` строит A2L (ASAM MCD-2 MC 1.6) прямо из
таблицы калибровок блока; `tools/a2lcheck.py <a2l> <bin>` проверяет его.

Готовые: `firmware/a2l/I862BB04.a2l`, `I865BB02.a2l`, `I862BB03.a2l`.
Подходят ко всем файлам той же версии (тюнинг меняет значения, а не
раскладку). CCon и MR2 — раскладка BB02 / BB04 соответственно; в MR2 описан
только бензиновый набор.

## Что внутри (BB04)

| | |
|---|---|
| оси (`AXIS_PTS`, `AX_xxx`) | 259 |
| калибровки (`CHARACTERISTIC`) | 2170: значения, массивы, кривые, карты; массивы кривых/карт разбиты на `_0`, `_1`… |
| переменные (`MEASUREMENT`) | 566: входы осей `AXIN_xxx`, RAM-величины из таблицы, установленные переменные круиза, педали, скорости |

`xxx` — индекс, который код передаёт геттеру (тот же, что в `calmap.py`).

Имена со смыслом — только там, где он установлен: `CRUISE_ENABLE`,
`LIMITER_ENABLE`, `CRUISE_SUPPORT`, `CRUISE_BTN_WIN_*`, `CRUISE_BTN_OPEN`,
`CRUISE_VSET_MIN`; пересчёты — км/ч (/64), °C (/128, ось −40…100), %
педали (/128). Остальное — сырые единицы.

## Допущения

- Карты `ROW_DIR` (X меняется быстрее, смещение `y*nx + x` — по коду
  геттера). Если редактор покажет карты перевёрнутыми — заменить на
  `COLUMN_DIR` в `RL_FNC_*`.
- Знак: по дескриптору; для u16, где значения явно отрицательные, взят
  `SWORD` (помечено «[знак по значениям]» в описании).
- Адреса — ЭБУ (`0x08000000 + смещение`). В WinOLS при импорте смещение
  `-0x08000000`.

## Проверка

- `a2lcheck.py`: каждая калибровка и ось читает ровно байты и значения из
  таблицы дескрипторов; покрыто 81411 из 81411 байт (BB04), перекрытий нет,
  ссылки целы. То же для BB02 и BB03.
- Независимый парсер `pya2l` 0.4.0 разбирает все три файла без ошибок и
  предупреждений.
