# S_CVN____startpower  2024__I862BB04_CCon.bin — разбор

## Что это на самом деле

Целиком **I865BB02**, а не BB04:

- код (`0x1000..0x5FFFF`, `0x80000..0xFFFF7`) совпадает с заводской BB02
  байт в байт, таблица векторов та же;
- калибровки = файл тюнера `S_CVN____startpower  2024__I865BB02.bin`
  плюс 50 байт: строки версии `I865BB02 → I862BB04` (`0x624B3`, `0x69036`,
  `0x690B8`, `0x690DC`, `0x6912B`, `0x76E8B`, `0x76EB1`);
- компенсаторы `0x7FFF8` / `0xFFFF8` подогнаны так, что блок отдаёт
  **заводские КС BB04**: калибровки `0A6E4403`, код `937D8A1D`.

Диагностика увидит «сток I862BB04», внутри — BB02 со startpower.

## Проверки

| Проверка | Результат |
|---|---|
| загрузчик `0x0..0xFFF` | `FF`, не пишется |
| КС калибровок / кода | сходятся (`m74ks.py check`) |
| карта калибровок | 2545 объектов, покрытие 97.8% |
| круиз, ограничитель, поддержка | 1, 1, 1 |
| окна кнопок | рабочие (как в BB02); эмуляция `0x83760` = заводская BB02 |

## Что меняет startpower (относительно стока BB02), 33 объекта

Имён нет, назначение — по осям:

- **педальные карты** `#6A8`, `#6A9` (3 × 16 × 12, педаль 0..100% × обороты):
  +1…13% на частичной педали — газ отзывчивее;
- 17×17 по оборотам × нагрузке: `#6CF..#6D2` (+0…50%), `#199 #19D #19F
  #1A7 #1A8` (+2…+9 единиц);
- кривые по оборотам `#123..#125` снижены на 10…82%; `#115`, `#38B`
  почти обнулены;
- кривая по напряжению бортсети `#30C` +44%, прочие мелкие.

С тюном `Vs008_70 tun` общих объектов всего 11 из 33 — это разные
настройки, напрямую не сравнимы.

## Вариант `_E2`

Отличается от этого файла 10 объектами (`#152`, `#3B4`, `#3B5`, `#560`,
`#561`, `#74D`, `#757`, `#75B`, `#8D1`, `#938`). По названию — Евро-2;
по коду не проверялось.

## Условия

- разъём ЭБУ перепинован F2 → A2 (`TSB1` у BB02 так же, как у BB04);
- данные регистратора при смене софта теряются (`ИнфоЗамены.txt`, папка
  «+КруизКонтроль_(-ПотеряРегистратора)»);
- раз блок выдаёт себя за BB04, обновление калибровок «под BB04» у
  дилера ляжет на код BB02.

## Почему не лить только область калибровок CCon поверх BB04

2538 обычных калибровок у BB04 и BB02 лежат по одинаковым адресам, но хвост
`0x74A30..0x76F7B` (~5 КБ: списки индексов `#9CE..#9EF`, конфигурация
драйвера CAN по `0x76264` и др.) у версий разложен по-разному. Код BB04
ссылается в калибровки 3175 раз, из них 344 — на данные, которые в BB02
другие; например, по `0x76264` у BB04 таблица CAN, у BB02 там `FF`.

Тот же тюнинг на родном BB04: `firmware/patched/I862BB04_startpower_CC2.bin`
(startpower 2023 BB04 + круиз). Набор и значения 33 объектов startpower
2023 BB04 и 2024 BB02 совпадают полностью.
