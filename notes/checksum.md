# Контрольная сумма M74.9 (ИТЭЛМА, Artery AT32F4xx)

Решено и проверено на всех 19 образах.

## Алгоритм

CRC-32, полином `0x04C11DB7`, **MSB-first, без рефлексии** входа и выхода,
init `0xFFFFFFFF`, финального XOR нет. Результат хранится **little-endian**.

В прошивке:

| Что | Адрес (flash, база `0x08000000`) |
|---|---|
| таблица CRC (256×4, совпадает с эталоном CRC-32/MPEG-2) | `+0x52A64` |
| обработчик байта | `+0x0B570C` |
| инициализация дескрипторов регионов | `+0x0B5740` |

Ядро обработчика:

```
ldrb ip, [r4], #1
eor.w ip, ip, r0, lsr #24      ; idx = байт ^ (crc>>24)
ldr.w r5, [r5, ip, lsl #2]     ; tab[idx]
eor.w r0, r5, r0, lsl #8       ; crc = tab[idx] ^ (crc<<8)
```

## Регионы

Дескрипторы строятся в SRAM `0x2000CB94`, три блока по `0x80` байт.

| КС | Покрывает | Хранится в |
|---|---|---|
| калибровки | `0x60000..0x7FFFB` | `0x7FFFC` |
| код | `0x1000..0x5FFFF` **и** `0x80000..0xFFFFB` | `0xFFFFC` |

Регион кода — **два несмежных сегмента**. Поэтому подбор по сплошному
диапазону не сходится, сколько ни перебирай.

## Фиксация КС (компенсаторы)

CRC линеен над GF(2), поэтому последние 4 байта региона можно решить так,
чтобы итоговая КС равнялась любому наперёд заданному значению:

- `0x7FFF8` — компенсатор региона калибровок
- `0xFFFF8` — компенсатор региона кода

В стоке оба = `FFFFFFFF` (не тронуты). Тюнер после правки калибровок
подбирает их так, чтобы обе КС остались **равны заводским**. Это и есть
«калибровки фиксации КС» из `ИнфоДвухрежимные.txt`.

`tools/kscomp.py` воспроизводит значения тюнера бит в бит на всех
проверенных файлах.

## Инструменты

```sh
python3 tools/m74ks.py check firmware/original/*.bin   # проверить
python3 tools/m74ks.py fix   вход.bin выход.bin        # честно пересчитать
python3 tools/kscomp.py файл.bin <КС_калибр> <КС_кода> # подобрать компенсаторы
```
