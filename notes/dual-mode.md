# Двухрежимные прошивки MR2 (бензин / ГБО)

Разобрано на `MR2(v2)_S_CVN_startpower_GBO-4_I862BB04_E2.bin` против его
однорежимной базы `S_CVN____startpower  2023__I862BB04_E2.bin`; у MR2 на
BB03 и BB02 устройство то же.

## Где что лежит

| Область | Что изменено |
|---|---|
| `0x0000..0x0FFF` (загрузчик) | ничего, пусто как везде |
| `0x1000..0x54F00` (код 1) | ~120 байт: хуки в геттерах калибровок `0x48DC..0x5270` |
| `0x60000..0x77000` (калибровки) | ничего — это набор для бензина |
| `0x80000..0xB9E40` (код 2) | ~180 байт: ещё хуки (напр. `0x9C53C`) |
| `0xB9E40..0xCD878` | **новый код MR2**, ~79 КБ, подпись `MRcode DiK(MEPro 2023)` |
| `0xBA080` | второй набор дескрипторов: u32 2545 + указатели |
| `0xCD878..0xE4878` | **копия калибровок для ГБО** (= `0x60000..0x77000` со сдвигом `+0x6D878`) |
| `0xE4878..0xFFFF7` | пусто |
| `0x7FFFC` / `0xFFFFC` | КС сходятся, подогнаны под заводские (у BB04 `0A6E4403` / `937D8A1D`) |

Всё — внутри `0x1000..0x100000`. За пределы 1 МБ код MR2 не ссылается
(единственная «дальняя» таблица — копия штатной карты секторов флеша
`0x54B20`, она есть и в стоке).

## Как переключается

В каждом геттере калибровок `ldr.w rX, [r0, r1, lsl #2]` (выбор
дескриптора по индексу) заменён на `bl` в заглушку `0xB9E78..`, которая
вызывает `0xB9E58`:

```
если таблица == 0x080416D4 (штатная) и SRAM[0x2000FFF4] == 1 (режим ГБО):
    таблица = 0x080BA084        ; второй набор дескрипторов
дескриптор = таблица[индекс]
```

Второй набор указывает в копию калибровок: например, флаг круиза
`0x63BFA` → `0xD1472` (проверено эмуляцией геттера в обоих режимах).

Флаг режима `SRAM 0x2000FFF4` ставит процедура `0xB9EC0` (вызывается из
задачи вместо `0x3E7F8`, в конце вызывает его). Способ задаёт бит 0 байта
настройки `0xCD871` (BB03 `0xCD1C1`, BB02 и CCon `0xCD481`):

| бит 0 | как переключается |
|---|---|
| 0 (во всех файлах) | режим = ДК2 (`SRAM 0x2D72`) < 164, проверяется постоянно |
| 1 | при `0x3D30` < 200 (двигатель стоит) и педали `0x3A16` > `0x2000` (≈64%): 5 вызовов подряд — режим переключается; пока педаль держат, повторно не переключает; отпустить и нажать снова — обратно |

Флаг в RAM, а штатный старт обнуляет SRAM `0x20000100..0x20020000`
(код старта MR2 не трогает) — после каждого сброса блока режим бензин.

Эмуляция (бит 0 = 1): педаль при стоящем двигателе `00000111`, отпустил
`11`, педаль на 800 об/мин `11111111`, низкий ДК2 `111`, педаль снова
`11111000`. При бите 0 = 0 педаль не действует, низкий ДК2 сразу даёт ГБО.

На машине без E2 (стоит второй лямбда-зонд) переключение по ДК2 не годится:
сигнал реального датчика падает ниже порога, например на отсечке топлива,
и блок будет прыгать на калибровки ГБО. Нужен бит 0 = 1.

## Что требуется от программы-прошивальщика

Записать `0x80000..0xFFFFB` **целиком, байт в байт**, включая участок
`0xB9E40..0xE4878`, который в обычных прошивках пустой. Если программа
пишет только «штатно занятые» участки, геттеры будут прыгать в стёртый
флеш — блок не заработает. КС кода в файле уже верная; пересчёт той же
CRC по тем же регионам (`0x1000..0x5FFFF` + `0x80000..0xFFFFB`) даст то
же значение.

Проверка без разработчика: после записи считать блок и сравнить с файлом
весь диапазон, особенно `0xB9E40..0xE4878`.

## Круиз в MR2 на BB04

В `MR2(v2)_S_CVN_startpower_GBO-4_I862BB04_E2.bin` круиз выключен и окна
кнопок схлопнуты — в **обоих** наборах калибровок. Включать пришлось бы
в двух местах (`0x63BE0..` и `0xD1458..`), и вторая правка попадает под
КС кода.

## Сборка под машину без E2

`tools/mr2.py build <MR2> <выход> --pedal --cruise --noe2 <ref-без-E2> <ref-E2>`.

`firmware/patched/MR2_I862BB04_startpower_GBO-4_pedal_noE2_CC2.bin` из
`MR2(v2)_S_CVN_startpower_GBO-4_I862BB04_E2.bin`:

- переключение педалью (`0xCD871` = 1) — единственная правка кода MR2;
- без E2 в обоих наборах: 9 объектов (`#3B4 #3B5 #74D #75B #87D #87F #880
  #8D1 #938`) и 6 байт хвоста `0x7668A..0x766A0` — значения из
  `S_CVN____startpower  2023__I862BB04_.bin`;
- круиз в обоих наборах (флаги + окна кнопок);
- обе КС пересчитаны: калибровки `9AAE8C4E`, код `71FA0DA6`.

Бензиновый набор совпадает с `I862BB04_startpower_CC2.bin` байт в байт
(кроме компенсатора и КС). ГБО-набор отличается от бензинового теми же
20 объектами, что в исходном MR2.

## Чем ГБО-набор отличается от бензинового (MR2 BB04)

20 объектов. Имён нет, смысл — по осям и значениям (предположения помечены).

| Объекты | Оси | На газе |
|---|---|---|
| `#199 #19D #19F #1A7 #1A8` | обороты × нагрузка, 17×17 | выше на низких и средних оборотах (напр. `#199` в середине нагрузки: 23→41, 50→66, 68→80), на высоких одинаково — похоже на углы опережения зажигания |
| `#6CF #6D0 #6D1 #6D2` | обороты × нагрузка, 17×17 | та же картина в другом масштабе (`#6D1`: 2944→5248 на низах, 11648→11776 вверху) |
| `#64A` | температура −40…100 °C (`#049`, ×128) | обнулена (на бензине 50…350) — похоже на температурную топливную поправку, ненужную газу |
| `#3D3`, `#636` | — | флаги 1 → 0 |
| `#518`, `#639`, `#63A` | — | → 25600 (было 5120 / 5760 / −2304) |
| `#462` | — | 12000 → 9000 |
| `#15B #429 #542 #544` | — | мелкие сдвиги |

Карт количества топлива среди отличий нет: топливо на газе пересчитывает
контроллер ГБО 4-го поколения, блок меняет в основном зажигание и
поправки. Если блок в режиме ГБО, а машина на бензине — на бензине будет
газовое (более раннее, если это УОЗ) зажигание на низах.
